# late-shift

A small library of Claude Code skills for people who build after the day job ends. Each is a markdown file
fixing one specific annoyance you hit at 11 PM.

It's for the person with a full-time job elsewhere, kids possibly asleep in the next room, and forty minutes
of runway. They're technically strong — the constraint is attention, not ability. Before this, they were
either editing their `CLAUDE.md` at midnight or just putting up with an assistant that answers every
question like it's defending a thesis.

The interesting part is that several of these skills exist to fill a seat a team would normally fill.
Working alone, nobody asks "why is this like this?" or "are you sure?" So `poke-holes` tries to break
your idea before you spend a weekend on it, and `paper-trail` records why the code is the way it is — the
model is the only party that ever held that reasoning.

Six skills, installed by copying a folder. Public and working; the honest user count is small.

**What it isn't:** a framework. No config, no build step, no dependencies. If you disagree with one,
you edit the markdown. That's the escape hatch on purpose.
